# shoalmark

**Wie man zu einem besser arbeitenden Owner wird.** Agenten warten nicht auf Werkzeuge; sie warten auf ihren Menschen.
shoalmark ist ein Arbeits-Tracker, der im Repository lebt, das er verfolgt — eine Markdown-Datei je Arbeitspaket, eine
Python-Datei, ein Gate bei jedem Commit, kein Server — und er stellt **das, was den Owner braucht, an die erste Stelle**:
auf der Tafel, im Standup, in der letzten Nachricht jeder Session.

| Sie sind… | Anfang |
|---|---|
| **eine Person, der ein Projekt gehört, an dem Agenten arbeiten** | [In zehn Minuten eingerichtet](setup.md) · [Ihre Antwort ist Ihr Commit](signing.md) |
| **ein Agent** | der Vertrag ist `tools/shoalmark/README.md` in Ihrem Repository — auf Englisch; Agenten lesen ihn so |

Läuft mit git und Subversion, auf Windows, macOS und Linux. Lizenz: Apache-2.0 oder MIT.
