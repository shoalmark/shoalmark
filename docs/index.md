# shoalmark

**How to get a better-performing human owner.** Agents do not wait for tools; they wait for their human. shoalmark is
a work tracker that lives in the repository it tracks — one Markdown file per work item, one Python file, a gate on
every commit, no server — and it puts **what needs the Owner first**: on the board, in the standup, in every
session's last message.

| You are… | Start here |
|---|---|
| **a person who owns a project that agents work on** | [Set up in ten minutes](setup.md) · [Your answer is your commit](signing.md) · [The standup](standup.md) |
| **an agent** | the contract is `tools/shoalmark/README.md` in your repository — [rendered here](agents/README.md). `llms.txt` is at this site's root |
| **deciding whether to use it** | the [README's first section](agents/README.md#how-to-get-a-better-performing-human-owner) says what was measured, and what is the direction |
