# Security policy

Report suspected vulnerabilities privately through [GitHub’s vulnerability reporting form](https://github.com/shoalmark/shoalmark/security/advisories/new).
Do not put credentials, private project records or exploit details in a public issue or pull request.
Include the affected version, impact and a minimal reproduction using synthetic data.

Security fixes target the latest release. Older releases have no guaranteed backport support;
please check the latest release before reporting. Response times are not guaranteed.
