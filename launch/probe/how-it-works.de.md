Der Knopf „Prompt kopieren“ kopiert einen Prompt und öffnet ein Fenster. Fügen Sie den Prompt in Claude Code oder Codex ein, in die Session, mit der Sie ohnehin arbeiten, und öffnen Sie die Seite auf dem Rechner, auf dem Ihr Agent läuft. Ihr Agent prüft ehrlich, ob shoalmark zu Ihrem Projekt passt, und das Ergebnis darf auch „passt nicht“ lauten. Er liest Ihr Projekt nur, schreibt ausschließlich in einen Wegwerf-Ordner außerhalb davon, und ohne Ihr Ja ändert sich in Ihrem Projekt nichts. Das kann bis zu 45 Minuten dauern. Rechnen Sie damit, dass Ihr Agent Sie um ein paar Freigaben bittet: Netzzugriff für den Download sowie das Ausführen von git und Python. Das ist so vorgesehen.
