Der Knopf „Prompt kopieren“ kopiert einen Prompt und öffnet ein Fenster. Fügen Sie den Prompt in Claude Code oder Codex ein, in die Session, mit der Sie ohnehin arbeiten, und öffnen Sie die Seite auf dem Rechner, auf dem Ihr Agent läuft. Der Prompt bittet Ihren Agenten, ehrlich zu prüfen, ob shoalmark zu Ihrem Projekt passt, und das Ergebnis darf auch „passt nicht“ lauten. Er bittet ihn, Ihr Projekt nur zu lesen, ausschließlich in einen Wegwerf-Ordner außerhalb davon zu schreiben und ohne Ihr Ja nichts in Ihrem Projekt zu ändern. Das kann bis zu 45 Minuten dauern. Rechnen Sie damit, dass Ihr Agent Sie um ein paar Freigaben bittet: Netzzugriff für seine Downloads von GitHub, das Ausführen von git (unter Subversion svn) und Python und, nur am Ende und nur auf Ihr Ja, das Öffnen unseres Rückmeldeformulars in Ihrem Browser. Das ist so vorgesehen.
