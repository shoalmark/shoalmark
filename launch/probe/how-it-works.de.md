Der Knopf „Prompt kopieren“ kopiert einen Prompt und öffnet ein Fenster. Füge den Prompt in Claude Code oder Codex ein, in die Session, mit der du ohnehin arbeitest, und öffne die Seite auf dem Rechner, auf dem dein Agent läuft. Der Prompt bittet deinen Agenten, ehrlich zu prüfen, ob shoalmark zu deinem Projekt passt, und das Ergebnis darf auch „passt nicht“ lauten. Er bittet ihn, dein Projekt nur zu lesen, ausschließlich in einen Wegwerf-Ordner außerhalb davon zu schreiben und ohne dein Ja nichts in deinem Projekt zu ändern. Das kann bis zu 45 Minuten dauern. Rechne damit, dass dein Agent dich um ein paar Freigaben bittet: Netzzugriff für seine Downloads von GitHub, das Ausführen von git (unter Subversion svn) und Python und, nur am Ende und nur auf dein Ja, das Öffnen unseres Rückmeldeformulars in deinem Browser. Das ist so vorgesehen.
