# Social images

shoalmark's images for profiles and link previews (the profile header, the repository card and the two link previews)
live in the organization's press kit, shoalmark/brand, beside the family's other marks:
[`social/`](https://github.com/shoalmark/brand/tree/main/social).

They moved there from this folder byte for byte. shoalmark/brand's commit
[`070a4dd`](https://github.com/shoalmark/brand/tree/070a4dd717d3f09c6b732d6ea07b9379928a2d1f/social) holds the ten
files this folder held: the SVG sources, their PNG and JPEG exports, and their README.

The site serves its own copies of the link previews, `docs/assets/preview.png` and `preview-de.png`.
