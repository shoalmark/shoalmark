# FM-080 — the docs do not say an answer needs a merge commit: a squash merge or a forge's web-editor commit breaks it

## What is true now

**Filed 2026-10-27, Proposed, from RV-3914 (P3) of the Auditor's review.** It comes after v0.20.2; nothing is built.

An answer needs a merge commit. A squash merge, or a commit signed by the forge's web editor, breaks it, and the docs do not say so.

## Why

An Owner who merges an answer the forge's default way loses the answer's proof, and nothing warned them.

## Done when

- The docs that describe answering say so, in the Owner's terms.
